以下我为你梳理了一份详尽的查询目标清单，分为五大核心维度，旨在支撑你提到的“择地”与“效率”决策逻辑：

---

### 一、 居住安全与地块物理属性（避坑与底线）

在台湾，地块的“先天条件”决定了价值的下限，这是估价和决策的第一步。

|**查询目标**|**具体指标/数据内容**|**推荐数据源**|**精度要求**|
|---|---|---|---|
|**土地使用分区**|住宅区（一/二/三）、商业区、工业区、农业区等|[TGOS 土地使用分区图](https://www.google.com/search?q=https://luz.tgos.tw/LP_WEB/&authuser=4)|矢量（地号级）|
|**地质安全**|土壤液化潜势（低/中/高）、断层带分布、顺向坡|[中央地质调查所](https://www.google.com/search?q=https://isdg.moeags.gov.tw/gissearch/&authuser=4)|1:5000 矢量|
|**淹水风险**|历史淹水记录、排水系统负荷、低洼地区分布|[经济部水利署](https://fhy.wra.gov.tw/fhyv2/)|矢量/1m DEM|
|**建筑物理指标**|屋龄分布、总楼层数、构造类型（RC/SRC）、容积率|[地政司建物登记数据](https://www.google.com/search?q=https://land.moi.gov.tw/&authuser=4)|物件级|

---

### 二、 极致通勤与时空效率（核心吸引力）

不能仅看距离，要看“体感通勤效率”。

|**查询目标**|**具体指标/数据内容**|**推荐数据源**|**工具/方法**|
|---|---|---|---|
|**等时圈分析**|步行 5/10/15 分钟、骑行 10 分钟的可达范围覆盖面积|Google Routes API / Mapbox|Isochrone Map|
|**轨道交通连接性**|捷运站出口位置、各站点班次频率、末班车时间|[PTX 交通行动服务平台](https://ptx.transportdata.tw/PTX/)|实时 API|
|**通勤线路质量**|换乘次数、捷运/公交是否有座位（起点站距离）、人行道连续性|Google Maps / 街道实景|路径规划权重|
|**停车便利性**|周边公有/私有停车场密度、路边车位抽签难易度|各县市交通局开放资料|POI 统计|

### 三、 社区品质与城市界面（溢价来源）

这部分数据需要“视觉化”和“标签化”，解决 GEE 分辨率不够的问题。

|**查询目标**|**具体指标/数据内容**|**推荐数据源**|**替代 GEE 的方案**|
|---|---|---|---|
|**高精度航拍**|社区内部中庭绿化、周边顶楼加盖情况、街道整洁度|[农林航空测量所 (DOP)](https://www.google.com/search?q=https://asrs.afasi.gov.tw/&authuser=4)|0.25m - 0.5m 影像|
|**建筑 3D 模型**|楼间距、采光遮挡分析、视野开阔度|Google 3D Tiles / Overture Maps|3D 矢量|
|**嫌恶设施距离**|变电所、加油站、殡仪馆、宫庙、高架桥噪音线|[TGOS](https://www.tgos.tw/) / OSM POI|空间缓冲区分析|
|**绿地品质**|公园面积、是否有儿童游具、受保护树木分布|各县市工务局公园路灯处|矢量多边形|

### 四、 生活机能与资源密度（长期持有的理由）

将“便利性”转化为可量化的分数。

|**查询目标**|**具体指标/数据内容**|**推荐数据源**|**粒度**|
|---|---|---|---|
|**商业能级**|连锁超市（全联/家福）、24h 超商、虾皮店到店密度|Google Places API / 官方公开资料|500m 半径聚合|
|**医疗层级**|医学中心 vs. 基层诊所（家医/牙科/儿科）的分布|[卫福部医事机构查询](https://ma.mohw.gov.tw/masearch/)|POI 等级权重|
|**教育资源**|明星学区边界、额满学校名单、幼儿园抽签率|各县市教育局|矢量学区图层|
|**金融机能**|银行、ATM 分布（反映地区商业活跃度）|金管会资料|POI 密度|

### 五、 价值趋势与人群属性（投资与共鸣）

结合实价登录与人口学，筛选出“适合的家庭画像”。

|**查询目标**|**具体指标/数据内容**|**推荐数据源**|**分析逻辑**|
|---|---|---|---|
|**房价热力图**|近 1-3 年单价/总价涨幅、成交活跃度分布|[内政部实价登录](https://lvr.land.moi.gov.tw/)|PostGIS 核密度分析|
|**人口结构**|户籍年龄分布（年轻人 vs. 长辈）、户均所得收入|[SEGIS 社会经济资料平台](https://segis.moi.gov.tw/)|统计区 (Level 5)|
|**入住率/空屋率**|依据低度用电调查判断社区活力|[内政部营建署](https://www.cpami.gov.tw/)|区域占比|
|**未来规划红利**|捷运兴建中线路、科学园区扩建规划、大型商场签约|政府公告 / 城市规划书|空间重叠分析|

### 💡 给后端研发的调研落地建议

1. 放弃栅格，拥抱矢量：
    
    针对社区决策，不再去搜 ee.Image。重点调研 WFS/WMS 服务（如台湾 NLSC 提供的服务），直接将矢量边界拉入你的 PostgreSQL。
    
2. 建立“空间权重模型”：
    
    你可以调研如何利用 PostGIS 的 ST_DWithin 或 ST_Distance 构建一套算法，例如：
    
    - `score = (dist_to_mrt * 0.4) + (dist_to_supermarket * 0.3) - (dist_to_pylon * 0.3)`
        
3. 关注“地号”与“门牌”：
    
    台湾最精准的地理单元是“地号”。建议调研如何将你的 land_shape_coordinate 与地籍图（Land Parcel）进行 100% 匹配。
